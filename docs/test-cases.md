> 适用：`mall-miniapp-uni` 前端 H5 手测（A 部分）与后端 FastAPI 接口测试（B 部分）。

## A. H5 前端手测用例（基于前端 mock）

> 运行 `npm run dev:h5` 后打开根路径（须有根目录 `index.html`）。mock 状态在浏览器内存，**改种子后需强刷（Ctrl+Shift+R）**。
> 种子要点：预置 10 件商品（「云朵抱枕靠垫」`onSale:false` 下架）、购物车 4 项（种子默认 `selected:false` 不勾选；**加购同样默认** **`selected:false`** **不勾选**）、地址 19 条（近上限）、订单 5 单覆盖全部状态。

## B. 后端接口测试用例（FastAPI 实现后，供 pytest / Postman / Apifox）

> 命名：`B<模块序号>_<编号>`。契约见 `docs/api-design.md`；错误码见 `docs/conventions/error-code.md`。
> 通用校验：未登录访问 🔒 接口返回 `401` 且同时为 HTTP 401；资源不存在统一返回 `404`（非模块段位码）；金额为数字（元）不返回 `¥`。
